# Stunt Racer · 赛车特技

横版卷轴的像素风特技驾驶小游戏。驾驶一辆车向右行驶，躲避迎面而来的 brake-failure 车辆，用跳跃高度和空中翻滚圈数换取分数。

**单次一条命，躲过 5 辆车即通关。**

## 直接玩

下载本仓库，双击打开根目录的 `index.html` 即可。

无需构建、无需安装依赖、无需联网。整个游戏是**单个 HTML 文件**，`assets/` 里的图片仅作为素材源保留，运行时不加载——它们已经内嵌进 `index.html` 了。

## 玩法

车辆自动向右行驶，迎面来车会随机以不同速度逼近。

| 操作 | 效果 |
|---|---|
| 短按（空格 / 点击） | 小跳 |
| 长按 | 起跳升高，超过 1.4 秒后开始前滚翻 |
| 落地前再轻触 | 修正落地角度，每次回正 30° |
| R 键 | 重开 |

评分取全部起跳的平均值（最多 5 次），满分 10：

```
s = 10 × ( 0.5 × apex/6.5  +  0.5 × turns/3.11 )
```

其中 `apex` 是车底达到的最大高度（上限 6.5 米），`turns` 是翻滚圈数（上限 3.11 圈）。

**坠毁即 0 分**——撞车、超窗、顶到广告牌都算，从第 1 辆重新来过。最高分存在 `localStorage`。

单局约 5–30 秒。

## 关于那个在线计数器

游戏结算屏会显示「全网开局 N 次」。它的实现方式是向作者的云数据库写入一条空记录并计数。

这件事你需要知道：

- **数据是匿名的**，只累加计数，不含任何身份、位置或设备信息
- 数据源表是 `insert-only`，没有更新和删除权限

如果你 fork 了本仓库，**不希望**继续计入作者的库，删掉 `index.html` 里这一段即可：

```html
<script>
  window.PUBLIC_CONFIG = { endpoint: '...', publishableKey: '...' };
</script>
```

删掉后 `initCloud()` 的守卫会自动跳过云逻辑，游戏功能完全不受影响，只是联网计数器显示为 `—`。

## 目录结构

```
index.html                        游戏本体（单文件，自包含）
assets/                           像素素材源文件
prototype/m1-sideview-greybox.html   侧视灰盒原型，逻辑层与成品逐字一致
docs/design-spec-v2.html          设计规格：参数表、难度曲线、决策日志
docs/mindmap.html                 全日成果思维导图
```

`index.html` 与 `prototype/m1-sideview-greybox.html` 的逻辑内核完全一致，前者是像素美术版，后者是灰盒版。想改玩法先看灰盒版，它没有视觉噪声。

## 素材

所有像素素材为 AI 生成后经量化处理，汽车 sprite 做了背景剔除。
